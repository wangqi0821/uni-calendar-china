# Uni 日历

按日期翻阅 Uni 的照片和视频历史归档。线上地址：<https://wangqi0821.github.io/uni-calendar-china/>

## 内容与使用范围

日历由 Uni 粉丝制作，内容仅用于获授权的日历用途；未经主人允许请勿用于其他用途。收录范围为 2020-06-10 至 2026-04-01，目前暂不更新。

照片、视频、原帖文字和日期均保留原始内容，没有生成或重绘图片。历史数据中已有的问号/乱码未作推测性替换。

## 当前版本

- 无需第三方样式脚本，样式和功能脚本由站点自身提供。
- 首页读取轻量日期索引，其中附带默认展示月份，首屏无需再请求一份月份数据；选择其他月份时按需下载并在当前页面内复用，月份文件名包含内容哈希。
- 图片使用原始同站文件，首张优先，其余延迟加载；视频在点击播放后才加载。
- 媒体失败时可以手动重试，或手动尝试固定版本的备用来源。
- 空日期保留当前选择，可以选择上/下一个有记录日期；分享地址保留所选日期。
- 数据或媒体加载失败会显示可操作的重试提示；快速切换日期时旧请求不会覆盖新结果。

## 部署与文件

继续使用现有 GitHub Pages 和主分支自动部署，无服务器、付费套餐或额外账号要求。

`index.html`、`assets/`、`data/` 和日历引用的原始媒体构成站点。`_config.yml` 排除源数据、工具和没有引用的媒体，原始媒体仍保留在 Git 仓库；不要添加 `.nojekyll`，否则这些排除规则不会生效。

`Uni.json` 是保留的原始数据。`tools/build_archive.py` 是可重复的数据转换工具，运行需要 Python 和 Pillow；`tools/test_archive.py` 验证全部记录、文字、顺序、哈希及原文件完整性。它们不会自动抓取或更新内容。

## 安全

登录会话文件不属于日历，禁止提交。`.gitignore` 与发布排除规则防止再次混入；删除当前文件不能撤销既有会话，也不能清除 Git 历史中的副本。相关账户应自行撤销已公开的登录会话。
